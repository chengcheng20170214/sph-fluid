# SPH 粒子流体模拟

零依赖、单文件 HTML 的 SPH（Smoothed Particle Hydrodynamics）粒子流体模拟。

## 特性

- 🔵💧 水（蓝色）— 重，低粘度
- 🟠🕯️ 蜡液（橙色）— 轻，高粘度
- 🖱️ 鼠标按住拖动搅拌
- 560+ 粒子，30+ FPS
- 半圆碗容器（开口朝上）

## 使用

双击 `sph-fluid.html` 即可在浏览器中运行。

如遇本地文件安全限制，可用：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/sph-fluid.html
```

## 技术实现

| 模块 | 实现 |
|---|---|
| SPH 核函数 | Poly6（密度）+ Spiky（压力梯度）+ 粘性拉普拉斯 |
| 邻居搜索 | 空间哈希网格 O(n) |
| 积分 | 子步进（每帧 3 次），提高稳定性 |
| 边界 | 半圆碗壁法线反弹 + 速度阻尼 |
| 交互 | 鼠标拖动力场，影响范围内粒子 |
